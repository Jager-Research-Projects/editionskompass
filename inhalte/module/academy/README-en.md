# Git Antipattern Academy · Version 4

Extract the entire ZIP, then open index.html or index-en.html in a browser. No installation, server or internet connection is required. Keep the assets folder alongside the HTML files.

Choose Deutsch or English in the header. Your choice is saved locally. Both languages share discovered cards and chapter best scores. Switching languages returns to the chapter overview; a round in progress is not resumed. All 25 learning cards and all exercise types are available in both languages. Original illustrations are unchanged, including any embedded text. The German original catalogue and an English learning catalogue are included.

Five chapters each cover five topics. Every round uses all five exercise types, with shuffled order and answers. Names of antipatterns are revealed on learning cards rather than tested. The causal chain supports drag and drop, card swapping, returning cards to the tray, and selecting a card then its destination using mouse, touch or keyboard. Check the chain only when ready; further corrections remain possible. The first check counts towards the round score.

Progress is stored only in your browser. If local storage is unavailable, progress lasts for the current session. Changing the folder path or browser may result in a different local learning record.

The application is based on the supplied conceptual catalogue of 19 October 2026. A smell is a clue, not proof. Legal topics are conceptual learning content, not a determination for a specific project. Assess concrete cases under the applicable law.

Both language versions have automated checks for exercise flows, correct and incorrect answers, chain moves, corrections, first-attempt scoring and shared card identities. A visual browser check could not be completed because local preview access was blocked in the execution environment.
